### auth
- 로그인
  - 가입한 E-Mail 과 PW 를 입력하고, 하단에 Login 버튼을 눌러 로그인을 수행한다.
  - 로그인 성공 시, Home 화면으로 이동한다.
  - 로그인 실패 시, 에러 메시지를 표시한다.
    - 에러메시지 표시는 ToastMessage 를 사용한다. 위치는 앱 하단이다.
  - E-Mail, PW 입력 TextField 는 입력값 검증을 수행한다.
    - E-Mail 에는 @ 가 붙어있는지 확인한다.
      - @ 가 없을 경우, TextField 하단에 "이메일 형식으로 입력해주세요." error 문구 표시한다
    - PW 는 최소 10자리 이상이여야 하며 대문자, 소문자, 특수문자를 포함한다.
      - 조건에 맞지 않을 경우, TextField 하단에 "대소문자, 특수문자 포함 10자리로 설정해주세요" error 문구 표시한다.
    - 입력 요구사항에 충족하지 않을 경우, TextField 테두리를 붉게 표시한다(error)
- 회원가입
  - 로그인화면의 최하단 "계정이 없으신가요? 여기를 눌러 가입하세요" 문구 클릭하여 이동
  - E-Mail 입력, E-Mail 인증코드, PW, PW 확인 4개의 TextField 존재.
  - 각 TextField 는 입력값 검증을 한다
    - E-Mail : @ 가 붙어있는지 확인
      - @ 가 없을 경우, TextField 하단에 "이메일 형식으로 입력해주세요." error 문구 표시한다
    - PW 는 최소 10자리 이상, 대문자, 소문자, 특수문자를 포함한다.
      - 조건에 맞지 않을 경우, TextField 하단에 "대소문자, 특수문자 포함 10자리로 설정해주세요" error 문구 표시한다.
    - PW 확인 : PW 와 동일한지 확인
      - 다를 경우, TextField 하단에 "비밀번호가 일치하지 않습니다." error 문구 표시한다.
      - 동일할 경우, error 문구 표시하지 않고 TextField 우측에 초록색 V 표시한다.
    - 입력 요구사항에 충족하지 않을 경우, TextField 테두리를 붉게 표시한다(error)
