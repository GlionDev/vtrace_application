### home
메인 화면
- 상단 남은 크레딧 및 무료 횟수 표시(하루 1건)
- 가운데 2개 탭 존재(내 파일에서 가져오기 / 링크로 가져오기)
  - 내 파일에서 가져오기 탭
    - 가운데 파일 가져오기 버튼 누르면 각 OS 에 맞는 파일 탐색기 에서 audio 파일 선택 가능
    - 파일 탐색기 열리기 전, 각 OS 에 맞는 권한 허용되었는지 확인 후 권한 허용 절차 진행
  - 링크로 가져오기
    - 링크 입력할 수 있는 TextField 존재. 입력 후 오른쪽 "분리" 누르면 API 호출
    - 외부 앱(유튜브) 에서 "공유" 를 통해 VTrace 를 선택하면, 해당 링크가 TextField 에 자동으로 입력되어야 함
    - 공유 시 `https://` 로 시작하는 URL 만 추출해서 TextField 에 넣어야 함.
