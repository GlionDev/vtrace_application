### pay
- 진입
  - 홈 화면에서 상단 남은 Token(무료한도) 클릭 시 이동
- 인앱 결제 기능
  - in_app_purchase 라이브러리 사용
  - 결제 상품 : 1000원, 3000원, 5000원
  - 결제 성공 시, ToastMessage 표시
  - 결제 실패 시, ToastMessage 표시
- UI
  - 결제 상품을 Radio 버튼으로 1000원, 3000원, 5000원 표시
  - 3개중 1개 선택 후 하단 구매하기 버튼 클릭
  - 인앱 결제 동작
  - 상단 우측 X 클릭 시 Home 으로 이동
